# Local maintenance build 6.0.0-owen.4

This release retains the 30 modules from .3 and adds four storage overlays against the same official 6.0.0 runtime. It does not upgrade the renderer or copy the user's vault/profile.

Windows resident NTFS files can report zero allocated blocks. File availability now checks native OFFLINE/RECALL attributes before classifying such files as cloud placeholders. The metadata-only probe batches paths, hides its short-lived process, bounds time and output, caches at most 4096 exact file fingerprints and fails closed on unknown attributes. A later successful probe recovers without restarting the app.

Code, notes and HTTP folders now plan updates on a separate folder view. A name conflict or rejected filesystem move leaves the live name, parent and sibling order intact; a subsequent valid update can succeed. Once a physical move succeeds, the live folder view follows the new disk path before dependent path updates.

The focused backend suite passes 35 tests, including native Windows Unicode resident files, OFFLINE attribute changes, probe failure/recovery, three storage domains and failed moves. These tests use temporary fixtures. Native GUI, real cloud-provider hydration, reboot and long-run acceptance are not established by these checks. The installed project records artifact hashes and each machine's adoption separately. API/MCP remain disabled.
