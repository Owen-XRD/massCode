# Local maintenance build 6.0.0-owen.5

The final review of .4 found that replacing a successful folder view could leave the already populated ID index pointing to old folder objects. Code, notes and HTTP now publish the folder array and ID index together, including immediately after a physical move. This retains .4's failure isolation without exposing stale objects to a later lookup.

Three new regressions warm the ID index, rename twice and verify each lookup plus the final disk path. The complete focused backend suite passes 38 tests. This supersedes .4; the official 6.0.0 Electron runtime, existing 34-module overlay closure, user vault/profile and disabled API/MCP remain unchanged in scope. Installed-module and entrypoint acceptance are recorded separately; this does not establish native GUI, real cloud-provider hydration or long-run acceptance.
